# Scurtături de taste

Aproape tot ce se face în Lanruj se poate face și fără mouse. Pagina aceasta arată toate combinațiile de taste și explică ce face fiecare. Le găsești oricând și în aplicație: apasă **Ctrl+?** sau deschide **☰ → Scurtături de taste**.

Câteva cuvinte despre cum sunt scrise tastele aici:

- **Ctrl+B** înseamnă: ții apăsat Ctrl și apeși B.
- **Ctrl+Shift+T** înseamnă: ții apăsate împreună Ctrl și Shift, apoi apeși T.
- **Ctrl+] / Ctrl+[** înseamnă două scurtături înrudite: prima face un lucru (mai mare), a doua pe dos (mai mic).
- **g g** înseamnă: apeși g, îl lași, apoi apeși din nou g.

Unele taste fac lucruri diferite, după locul în care te afli. Ctrl+I, de exemplu, adaugă ziua în Index pe pagina unei zile, dar în jurnal face textul cursiv. Unde se întâmplă asta, tabelele de mai jos o spun.

## Peste tot

Tastele acestea merg oriunde în aplicație.

| Taste | Ce fac |
|---|---|
| **Ctrl+F** | Caută peste tot: în paginile zilelor, săptămânilor și lunilor, în jurnal, în bilete, în Monitorizare și în Index. Poți căuta mai multe cuvinte, o expresie exactă între ghilimele sau poți lăsa un cuvânt pe dinafară cu semnul minus (`-cuvânt`). |
| **Ctrl+N** | Deschide un bilet nou: o hârtiuță pentru o idee pe care vrei s-o notezi repede. Rămâne lipită pe caiet, pe fiecare pagină, până o ștergi. |
| **Ctrl+I** | Adaugă în Index ziua pe care o vezi, ca s-o găsești ușor mai târziu. În jurnal, Ctrl+I face textul cursiv. |
| **F9** | Strânge bara laterală până rămân doar iconițele sau o întinde la loc. |
| **F11** | Mărește fereastra cât tot ecranul sau o readuce la mărimea de dinainte. |
| **Shift+F11** | Ecran complet, doar cu paginile: bara laterală și antetul dispar. Ieși cu Esc. |
| **Ctrl+,** | Deschide Setările. |
| **Ctrl+?** | Arată fereastra cu toate scurtăturile de taste. |
| **F1** | Deschide ghidul, care explică aplicația pas cu pas. |
| **Ctrl+W** | Închide fereastra. Dacă iconița din systray e pornită, Lanruj rămâne deschis în fundal și îl poți redeschide de acolo. |
| **Ctrl+Q** | Închide Lanruj de tot. |

## Deplasare

| Taste | Ce fac |
|---|---|
| **Alt+←** sau **Ctrl+Page Up** | Te duce la pagina de dinainte: ziua, săptămâna sau luna de dinainte, ori ziua de jurnal de dinainte, după ce e deschis. |
| **Alt+→** sau **Ctrl+Page Down** | Te duce la pagina de după, la fel. |
| **Alt+Home** | Te aduce înapoi la azi. În jurnal, deschide jurnalul de azi. |
| **Ctrl+G** | Deschide un calendar, ca să sari la orice dată. |
| **Ctrl+P** | Tipărește pagina deschisă. În jurnal, tipărește textul zilei respective, pe foi A4. |
| **Ctrl+Shift+E** | Salvează pagina deschisă ca fișier PDF. În jurnal, salvează textul zilei respective, pe foi A4. |

## Paginile zilei, săptămânii și lunii și Planurile

Pe paginile acestea scrii rânduri scurte: sarcini, evenimente și notițe. Le scrii în câmpul din josul paginii.

| Taste | Ce fac |
|---|---|
| **Enter** (în câmpul de jos) | Adaugă rândul scris. Începe-l cu `.` pentru o sarcină, cu `o` pentru un eveniment sau cu `-` pentru o notiță (vezi [Semnele de la începutul rândului](#semnele-de-la-începutul-rândului)). |
| **↑ / ↓** | Alege rândul de deasupra sau de dedesubt. |
| **Enter** (pe un rând ales) | Te lasă să modifici rândul ales. |
| **Ctrl+Enter** | Bifează sarcina aleasă ca făcută sau o debifează. |
| **Delete** | Șterge rândul ales. |
| **Tab / Shift+Tab** | Mută rândul ales sub cel de deasupra, ca subpunct, sau îl scoate de acolo. |
| **Esc** | Te întoarce în câmpul de scris de jos. |

Cât timp modifici un rând:

| Taste | Ce fac |
|---|---|
| **Ctrl+K** | Face din textul selectat o legătură web. |
| **Enter** | Salvează schimbarea. |
| **Esc** | Renunță la schimbare și lasă rândul cum era. |

## Jurnal

Jurnalul e locul în care scrii pe larg, câte o pagină pe zi. Tastele de formatare merg în două feluri: dacă ai selectat un text, se aplică pe el; dacă n-ai selectat nimic, se aplică pe ce scrii de acum înainte. Aceleași taste apăsate încă o dată scot formatarea.

### Textul

| Taste | Ce fac |
|---|---|
| **Ctrl+B** | Îngroșat. |
| **Ctrl+I** | Cursiv. |
| **Ctrl+U** | Subliniat. |
| **Ctrl+D** sau **Ctrl+Shift+X** | Tăiat. |
| **Ctrl+Shift+F** | Alege fontul textului selectat sau, dacă n-ai selectat nimic, al întregului rând. Fontul se poate schimba doar în jurnal. |
| **Ctrl+] / Ctrl+[** | Face textul selectat sau rândul mai mare ori mai mic. |
| **Ctrl++ / Ctrl+- / Ctrl+0** | Face tot jurnalul mai mare sau mai mic ori îl readuce la mărimea din restul aplicației. Lanruj ține minte mărimea aleasă. |
| **Ctrl+Shift+H** | Pune un marker galben pe textul selectat, ca un evidențiator. Dacă textul e deja marcat, markerul dispare. |
| **Ctrl+Shift+G** | Deschide culorile, ca să alegi o culoare pentru text sau pentru marker. Te miști cu săgețile și alegi cu Enter. |
| **Ctrl+Space** | Scoate formatarea și culorile de pe textul selectat. Legăturile rămân. |

### Titluri, citate și liste

| Taste | Ce fac |
|---|---|
| **Ctrl+Shift+T** | Face din rând un titlu. Încă o dată, îl face text obișnuit. |
| **Ctrl+Shift+S** | Face din rând un subtitlu, mai mic decât un titlu. Încă o dată, îl face text obișnuit. |
| **Ctrl+Shift+Q** | Face din rând un citat. Încă o dată, îl face text obișnuit. |
| **Ctrl+Shift+8** | Face o listă cu buline din rândul curent sau din rândurile selectate. |
| **Ctrl+Shift+7** | Face o listă numerotată. |
| **Ctrl+Shift+9** | Face o listă cu căsuțe de bifat, câte una în fața fiecărui rând. |
| **Tab / Shift+Tab** | Într-o listă, coboară rândul cu un nivel, într-o sublistă, sau îl urcă înapoi cu un nivel. |
| **Enter** | Într-o listă, începe un rând nou cu același semn. Pe un rând gol, urcă un nivel sau încheie lista. |
| **Backspace** | Imediat după semnul listei, urcă rândul cu un nivel sau scoate semnul. |
| **Ctrl+Enter** | Bifează sau debifează căsuța rândului, într-o listă cu căsuțe. |

### Legături, ora și anularea

| Taste | Ce fac |
|---|---|
| **Ctrl+K** | Adaugă o legătură web: pe textul selectat sau ca text nou, împreună cu adresa lui. Adresele web pe care le scrii devin și singure legături. |
| **Ctrl+L** | Leagă textul selectat de o zi, de un anumit rând dintr-o pagină, de o pagină din Index sau de Monitorizare. Cu Ctrl+clic pe legătură ajungi acolo. |
| **Ctrl+Shift+O** | Scrie ora de acum pe un rând nou, ca început al unei noi însemnări în jurnalul zilei. |
| **Ctrl+Z / Ctrl+Shift+Z** | Anulează ultima schimbare sau o face din nou. |

## Migrare

Seara, migrarea te ajută să hotărăști ce faci cu sarcinile pe care nu le-ai terminat. Le ia pe rând, una câte una; tastele sunt simple litere, fără Ctrl.

| Taste | Ce fac |
|---|---|
| **Ctrl+M** | Pornește migrarea sarcinilor neterminate. |
| **m** sau **Enter** | Mută sarcina pe pagina următoare: mâine, săptămâna viitoare sau luna viitoare. |
| **p** | Programează sarcina pe o zi sau pe o lună aleasă de tine. |
| **r** | Renunță la sarcină: hotărăști că nu mai merită făcută. |
| **l** | Lasă sarcina unde este. |
| **↑ / ↓** | Trece la sarcina de deasupra sau de dedesubt. |
| **Esc** | Oprește migrarea deocamdată. O poți relua oricând vrei. |

## Tastele Vim

Dacă ești obișnuit cu editorul Vim, te poți mișca prin pagini cu tastele lui. Le pornești din **Setări**. Merg pe paginile zilei, săptămânii și lunii și în Planuri, cât timp nu scrii într-un câmp.

| Taste | Ce fac |
|---|---|
| **j / k** | Rândul de dedesubt sau de deasupra. |
| **g g / Shift+G** | Primul sau ultimul rând al paginii. |
| **h / l** | Pagina de dinainte sau de după. |
| **t** | Înapoi la azi. |
| **x** | Bifează sau debifează sarcina aleasă. |
| **i** | Modifică rândul ales. |
| **o** | Scrie un rând nou în câmpul de jos. |
| **d d** | Șterge rândul ales. |
| **> > / < <** | Mută rândul sub cel de deasupra sau îl scoate de acolo. |
| **/** | Caută peste tot. |
| **Esc** | Iese din câmpul de scris, ca tastele Vim să meargă din nou. |

## Semnele de la începutul rândului

Pe paginile zilei, săptămânii și lunii, primul semn al rândului îi spune lui Lanruj ce fel de rând este. Scrii semnul, un spațiu și apoi textul, apoi apeși Enter.

| Scrii | Obții |
|---|---|
| `. Cumpără pâine` | O sarcină. |
| `o 10:00 Dentist` | Un eveniment; ora nu e obligatorie. |
| `- Autobuzul a întârziat` | O notiță. |
| `. * Trimite raportul` | O sarcină importantă, însemnată cu o steluță. |
| `- ! Un magazin de hărți vechi` | O idee, însemnată cu un semn de exclamare. |

## Scurtături din sistem

Două lucruri nu țin de Lanruj însuși:

- Când blochezi ecranul (de exemplu cu **Super+L**), Lanruj se poate bloca odată cu el. Pornește **Se blochează odată cu ecranul** din **Setări → Siguranță**.
- Ca să deschizi Lanruj cu o combinație de taste, adaugă o scurtătură proprie în setările de tastatură ale sistemului, care pornește Lanruj.
