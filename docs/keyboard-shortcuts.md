# Keyboard shortcuts

Almost everything in Lanruj can be done without the mouse. This page lists every key combination and explains what it does. You can also see them in the app at any time: press **Ctrl+?** or open **☰ → Keyboard Shortcuts**.

A few words about how the keys are written here:

- **Ctrl+B** means: hold Ctrl and press B.
- **Ctrl+Shift+T** means: hold Ctrl and Shift together, then press T.
- **Ctrl+] / Ctrl+[** means two related shortcuts: the first does one thing (larger), the second the opposite (smaller).
- **g g** means: press g, release it, then press g again.

Some keys do different things depending on where you are. Ctrl+I, for example, adds the day to the Index on a day page, but makes text italic in the journal. Where this happens, the tables below say so.

## General

These work everywhere in the app.

| Keys | What they do |
|---|---|
| **Ctrl+F** | Searches everywhere: the day, week and month pages, the journal, the notes, Tracking and the Index. You can search for several words, for an exact phrase in quotes, or leave a word out with a minus sign (`-word`). |
| **Ctrl+N** | Opens a new note: a small slip of paper for an idea you want to jot down quickly. It stays stuck on the notebook, on every page, until you delete it. |
| **Ctrl+I** | Adds the day you are looking at to the Index, so you can find it again easily. In the journal, Ctrl+I makes text italic instead. |
| **F9** | Shrinks the sidebar down to its icons, or expands it again. |
| **F11** | Maximizes the window to fill the screen, or brings it back to its previous size. |
| **Shift+F11** | Full screen with only the pages: the sidebar and the header disappear. Press Esc to leave it. |
| **Ctrl+,** | Opens Preferences. |
| **Ctrl+?** | Shows the window with all the keyboard shortcuts. |
| **F1** | Opens the guide, which explains the app step by step. |
| **Ctrl+W** | Closes the window. If the tray icon is turned on, Lanruj keeps running in the background and you can open it again from there. |
| **Ctrl+Q** | Quits Lanruj completely. |

## Moving around

| Keys | What they do |
|---|---|
| **Alt+←** or **Ctrl+Page Up** | Goes to the previous page: the previous day, week or month, or the previous journal day, depending on what is open. |
| **Alt+→** or **Ctrl+Page Down** | Goes to the next page, in the same way. |
| **Alt+Home** | Takes you back to today. In the journal, it opens today's journal. |
| **Ctrl+G** | Opens a calendar so you can jump to any date. |
| **Ctrl+P** | Prints the page that is open. In the journal, it prints the text of that day on A4 sheets. |
| **Ctrl+Shift+E** | Saves the open page as a PDF file. In the journal, it saves the text of that day on A4 sheets. |

## Day, week and month pages and the future log

On these pages you write short lines: tasks, events and notes. You type them in the field at the bottom of the page.

| Keys | What they do |
|---|---|
| **Enter** (in the bottom field) | Adds the line you have typed. Start it with `.` for a task, `o` for an event or `-` for a note (see [Signs at the start of a line](#signs-at-the-start-of-a-line)). |
| **↑ / ↓** | Selects the line above or below. |
| **Enter** (on a selected line) | Lets you edit the selected line. |
| **Ctrl+Enter** | Ticks the selected task as done, or unticks it. |
| **Delete** | Deletes the selected line. |
| **Tab / Shift+Tab** | Moves the selected line under the one above it, as a sub-item, or takes it back out. |
| **Esc** | Takes you back to the writing field at the bottom. |

While you are editing a line:

| Keys | What they do |
|---|---|
| **Ctrl+K** | Turns the selected text into a web link. |
| **Enter** | Saves the change. |
| **Esc** | Discards the change and leaves the line as it was. |

## Journal

The journal is where you write at length, one page per day. The formatting keys work in two ways: if you have selected some text, they apply to it; if you have not, they apply to what you type next. Pressing the same keys again removes the formatting.

### Text

| Keys | What they do |
|---|---|
| **Ctrl+B** | Bold. |
| **Ctrl+I** | Italic. |
| **Ctrl+U** | Underline. |
| **Ctrl+D** or **Ctrl+Shift+X** | Strikethrough. |
| **Ctrl+Shift+F** | Chooses the font of the selected text or, if nothing is selected, of the whole line. Fonts can be changed only in the journal. |
| **Ctrl+] / Ctrl+[** | Makes the selected text, or the line, larger or smaller. |
| **Ctrl++ / Ctrl+- / Ctrl+0** | Makes the whole journal larger or smaller, or brings it back to the size used in the rest of the app. Lanruj remembers this size. |
| **Ctrl+Shift+H** | Puts a yellow marker on the selected text, like a highlighter pen. If the text is already marked, the marker is removed. |
| **Ctrl+Shift+G** | Opens the colors, so you can choose a color for the text or for the marker. Use the arrow keys to move and Enter to choose. |
| **Ctrl+Space** | Clears the formatting and the colors from the selected text. Links are kept. |

### Headings, quotes and lists

| Keys | What they do |
|---|---|
| **Ctrl+Shift+T** | Turns the line into a heading. Press again to make it plain text. |
| **Ctrl+Shift+S** | Turns the line into a subheading, smaller than a heading. Press again to make it plain text. |
| **Ctrl+Shift+Q** | Turns the line into a quote. Press again to make it plain text. |
| **Ctrl+Shift+8** | Makes a bulleted list from the current line or from the selected lines. |
| **Ctrl+Shift+7** | Makes a numbered list. |
| **Ctrl+Shift+9** | Makes a checklist, with a box in front of each line. |
| **Tab / Shift+Tab** | In a list, moves the line one level down, into a sub-list, or one level back up. |
| **Enter** | In a list, starts a new line with the same sign. On an empty line, it moves up a level or ends the list. |
| **Backspace** | Right after the list sign, moves the line up a level or removes the sign. |
| **Ctrl+Enter** | Ticks or unticks the box of the line in a checklist. |

### Links, time and undo

| Keys | What they do |
|---|---|
| **Ctrl+K** | Adds a web link: on the selected text, or as a new piece of text, together with its address. Web addresses you type are also turned into links on their own. |
| **Ctrl+L** | Links the selected text to a day, to a particular line on a page, to a page of the Index or to Tracking. Ctrl+click on the link takes you there. |
| **Ctrl+Shift+O** | Writes the current time on a new line, to start a new entry in the day's journal. |
| **Ctrl+Z / Ctrl+Shift+Z** | Undoes the last change, or redoes it. |

## Migration

In the evening, migration helps you decide what to do with the tasks you did not finish. It takes them one by one; the keys are plain letters, without Ctrl.

| Keys | What they do |
|---|---|
| **Ctrl+M** | Starts the migration of unfinished tasks. |
| **m** or **Enter** | Moves the task to the next page: tomorrow, next week or next month. |
| **p** | Schedules the task for a day or a month you choose. |
| **r** | Drops the task: you decide it is no longer worth doing. |
| **l** | Leaves the task where it is. |
| **↑ / ↓** | Goes to the task above or below. |
| **Esc** | Stops the migration for now. You can pick it up again whenever you like. |

## Vim keys

If you are used to the Vim editor, you can move around the pages with its keys. Turn them on in **Preferences**. They work on the day, week and month pages and in the future log, while you are not typing in a field.

| Keys | What they do |
|---|---|
| **j / k** | The line below or above. |
| **g g / Shift+G** | The first or the last line of the page. |
| **h / l** | The previous or the next page. |
| **t** | Back to today. |
| **x** | Ticks or unticks the selected task. |
| **i** | Edits the selected line. |
| **o** | Writes a new line in the field at the bottom. |
| **d d** | Deletes the selected line. |
| **> > / < <** | Moves the line under the one above it, or takes it back out. |
| **/** | Searches everywhere. |
| **Esc** | Leaves the writing field, so the Vim keys work again. |

## Signs at the start of a line

On the day, week and month pages, the first character of a line tells Lanruj what kind of line it is. Type the sign, a space and then the text, and press Enter.

| You type | You get |
|---|---|
| `. Buy bread` | A task. |
| `o 10:00 Dentist` | An event; the time is optional. |
| `- The bus was late` | A note. |
| `. * Send the report` | An important task, marked with a star. |
| `- ! A shop for old maps` | An idea, marked with an exclamation mark. |

## Shortcuts from the desktop

Two things do not depend on Lanruj itself:

- If you lock the screen (for example with **Super+L**), Lanruj can lock itself at the same time. Turn on **Lock when the screen locks** in **Preferences → Security**.
- To open Lanruj with a key combination, add a custom shortcut in your desktop's keyboard settings that runs Lanruj.
